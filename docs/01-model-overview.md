# 01 · MiniMax H3（海螺 3.0 / Hailuo 03）模型总览

> 本文汇总 MiniMax 官方文档、官方 GitHub 仓库与多方评测对 H3 的描述。凡是官方文档与第三方说法不一致的地方，都在「分歧」一节单独列出，以官方为准。

## 1. 名称与版本

| 叫法 | 来源 | 说明 |
|------|------|------|
| **MiniMax H3** / `MiniMax-H3` | 官方模型 ID | API、ComfyUI、开源仓库统一使用 |
| 海螺 3.0 / Hailuo 3.0 | 海螺 AI 应用、社区 | 海螺 AI 是 MiniMax 面向 C 端的视频应用 |
| Hailuo 03 / 海螺 03 | 第三方站点 | 同一模型的别名，注意不要与快手 Kling O3 混淆 |

- 2026‑07‑17 WAIC 预告，**2026‑07‑31 正式发布**（官方 Release Notes 条目日期 Jul. 31, 2026）。
- 前代为 Hailuo 2.3（1080P、约 10 秒、无原生音频）。H3 的核心跃迁：**原生 2K、4–15 秒、音画一次生成（32 kHz 立体声）、全能参考（Omni Reference）、单次生成内多镜头切换**。

### 2.1 模型变体（API 枚举）

| 模型 ID | 定位 | 分辨率 | 时长 |
|---------|------|--------|------|
| `MiniMax-H3` | 高质量成片 | 768P / **2K** | 4–15 s |
| `MiniMax-H3-Highspeed` | 质量与速度平衡 | 480P / 768P | 4–15 s |
| `MiniMax-H3-Lite` | 轻量低价 | 480P / 768P | 4–15 s |
| `MiniMax-H3-Max` | fal 后训练的高速变体（ComfyUI 文档），支持 `prompt_expansion_mode` | 480P / 768P | 5–15 s |

配套服务：
- **H3-Context-IR**：提示词增强/重写服务（托管，不开源）。官方 README 原话：*"H3-Context-IR is critical to the quality of the final output"*。可单独调用 `POST /v2/h3_context_ir` 只拿回改写后的结构化提示词。
- **H3-Regenerate-2K**：把 768P 成片重生成为 2K（不开源）。工作流上常见「768P 草稿 → 选中 → 2K 重生成」。

## 3. 架构要点（官方 README）

- **H3-Encoder**：复用 Qwen3-VL-32B 全部预训练权重，取第 50 层 hidden states 送入主干。
- **H3-VisualVAE**：时间因果视频自编码器，空间压缩 16×、时间压缩 4×、24 个潜变量通道（f16t4d24）。
- **H3-AudioVAE**：左右声道共享编解码器、独立处理；32 kHz → 40 Hz 潜变量序列。
- **H3-Omni-Transformer**：33B 稠密单流 Transformer，其中约 13B 位于 AdaLN 分支（推理可预计算缓存，不必加载）。视频与音频潜变量**联合预测**，再分别解码。
- 开源权重：`MiniMax-H3 Base FL2VA`（文生/首尾帧）与 `MiniMax-H3 Base Ref2VA`（参考生）两套 BF16 检查点，CFG 蒸馏版本，许可为 MiniMax H3 Community License；支持 SGLang / vLLM / diffusers / ComfyUI 本地推理（示例为 4 卡）。开源版仅 768P，且**不含** Context-IR 与 2K 重生成。ComfyUI 文档称本地商用需向 Comfy 购买商业授权。

## 5. 与同类模型的位置

| 维度 | H3 | Seedance 2.0 / 2.5 | Kling 3.0 | Veo 3.1 |
|------|----|--------------------|-----------|---------|
| 最高分辩率 | 2K | 1080P–2K | 4K | 4K |
| 单次时长 | 15 s | 2.5 版可达 180 s | 多镜头 | ~8 s |
| 原生音频 | 是（立体声） | 是 | 是 | 是 |
| 多参考 | 9 图 + 3 视频 + 3 音频 | 多图 | 多图 | 较少 |
| 评测观感（MindStudio、Kie 汇总） | 角色保持、唇形、人声保持好，动作偏慢偏稳重；大幅运镜与特效镜头较弱 | 更"电影感"、动作更有表现力，部分场景更糊 | 运镜与多镜头强 | 原生分辨率高 |
| 成本 | 约为主流旗舰 1/3 | — | — | 高 |

结论：**H3 的强项正好落在竖屏短剧的需求区**——对白戏、正反打、角色面部与服装一致、音画同出、低单价；弱项（大场面运镜、特效、精确文字）在短剧里可用剪辑和后期规避。

## 6. 各来源分歧与取舍

| 议题 | 官方 | 第三方说法 | 本项目采用 |
|------|------|-----------|-----------|
| 最短时长 | 4 s | 5 s（Comfy、APIDot、Morphed） | 4 s（API 枚举） |
| 2K 像素 | 短边 1440（Morphic） | 2560×1440 / 2976×1248@21:9 | 短边 1440 |
| 参考文件总数 | 指南 12；API 页按类型 9+3+3 | 12 | 以 12 为安全上限 |
| 开源权重 | README 已给出 HF 检查点与 License | 部分文章称"未发布" | 已开源 768P Base，2K 与 IR 未开源 |
| 视频扩展 / 指令编辑 / 声音克隆 | README 未列；Ref2VA 可继续视频（`video continuation`）、复用音色（`audio reference`） | Morphic/Pixo 称支持编辑、换声 | 通过 Ref2VA 实现，不依赖独立"编辑"接口 |
| 提示词语言 | 官方 skill 要求描述段用英文、对白保留原语言 | 国内教程直接中文 | 结构化段用英文，`<d>[Chinese] …</d>` 写中文台词 |
