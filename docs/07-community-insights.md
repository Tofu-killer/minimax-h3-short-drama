## 3. 公众号 / 博客（中文）

## 5. 评测中的弱点（务必在分镜阶段规避）

- 动作偏慢、偏稳重，打戏软（MindStudio；JZL 节点为此写了「攻防同步、拒绝回合制」润色规则）。
- 大幅运镜、特效镜头较弱（Kie 汇总、@aiwarts）。
- 视频延展时背景人物移位、道具凭空出现（MindStudio）。
- 长结构化提示词在打戏段被截断（MindStudio）。
- 用英文提示要求外语台词会带口音；台词写目标语言（MindStudio）。
- 原生对白不等于完美语音：发音、情绪、说话人身份、口型都要实测再交付（ugcmaker）。

## 6. 平台差异提醒

同一个 H3 在不同平台能力不同：HelloGen「H3 Unlimited」只收图片参考、720p 最多 5 张；Kapwing 只出 768p；RunDiffusion Ref‑to‑Video 最多 5 图；Morphed 的集成不保证音频输出；ComfyUI 的 H3 Max 变体由 fal 后训练、不支持 2K。写流水线时**以官方 API 为准**，第三方平台的限制单独适配。
