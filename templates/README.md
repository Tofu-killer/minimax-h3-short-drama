# 提示词模板

可直接复制到海螺 AI 应用、ComfyUI H3 节点或 API `text` 字段。语法说明见 `docs/04-prompt-engineering.md`。

| 文件 | 用途 |
|------|------|
| `three-part-t2va.md` | 纯文字生成（T2VA） |
| `three-part-i2va.md` | 首帧图生视频（I2VA），关键脸部镜头 |
| `three-part-fl2va.md` | 首尾帧（FL2VA），段落衔接转场 |
| `six-part-ref2va.md` | 全能参考（Ref2VA），标准短剧段落 |
| `dialogue-patterns.md` | 对白/旁白/跨镜头台词/音色参考写法 |
| `producer-brief.md` | 一段式「制片人简报」，交给 H3‑Context‑IR 自动展开 |
