# 迭代 8：端到端测试（2026-11-21）

前几轮分别测了后期链路和创作链路，中间的衔接没有人走过。这一轮请一个没有上下文的 agent 拿五条已有的片段（真实 H3 成片切出来的，有中文对白）从头做到尾：按片子补分镜并校验 → 出提示词并机检 → 质检五条片段 → 选片、剪辑单、字幕、混音成片 → 导出可继续编辑的工程。条件是用户**没有任何参考图和音色样本**。

**结果**：整条链在 CPU 上跑通，成片、字幕、OTIO / FCP7 XML / CMX3600、剪映草稿都交付。它对每一份脚本报告都做了独立核对（逐帧 PSNR、第二遍语音识别、语音频段能量、ebur128 响度、音画互相关）：质检和装配的报告都可信。它的结论仍是「不猜做不完」——卡在创作那一半。

## 代价最高的三个

| 问题 | 性质 | 修复 |
|------|------|------|
| **没有参考图这条路走不通**：照文档用默认的 `ref2va`，脚本出的是定义段和保留段都为空的六段式，机检五段全 FAIL；一个没图的道具让校验报错、整集提示词都不出；出路（`t2va`、`--force`）哪份文档都没写 | 步骤接不上 + 文档缺失 | 没有任何参考媒体的 `ref2va` 段自动按纯文字（三段式 `t2va`）出，并在 `.media.json` 里记下真实模式；道具没图从报错降为警告（提示词里用文字描述它）；文档写明这条路径和 `--force` |
| **切点改了之后的字幕**：重新对时把一句字幕挪早了 0.6 s（落在开门声上）而没有任何提示，出点还越过切点一帧；`--dry-run` 和 OTIO 导出不报「字幕过期」；两个导出脚本把另一版剪辑的混音原样接了进去 | 脚本缺陷 | 字幕不再越过本段出点；入点没动而起点挪了 0.3 s 以上的句子标 `moved`；预览和两个导出脚本都报字幕过期；混音报告带上切点签名，导出时发现混音来自另一版剪辑会警告 |
| **分镜表达不了片子里有的东西**：只听得见的人、一段跨两个地方、开新场景的段既要站位又要承接、`end_hold` 既管提示词又管剪辑 | 文档缺失 + 校验过严 | 画外的台词标 `offscreen`，说话人不必绑进该段；开新场景的段有 `stagings` 就可以不写 `continuity`；一段一个场景的规则与 `end_hold` 在「给已有片段补分镜」时的写法写进文档 |

## 其它

| 发现 | 修复 |
|------|------|
| 联络表按文件名命名，而 `comfy_submit.py` 存下的片段常常同名（`ComfyUI_00001_.mp4`）：互相覆盖，表上看不出是哪一段 | 按片段所在的文件夹命名（`s03_101_<文件>_sheet.png`），同一次运行里不覆盖 |
| `_prev_*` 里被替换掉的旧片段被递归通配符带进质检，当成候选 | 五个质检脚本都跳过并提示 |
| 质检的终端输出只有文件名，看不出是哪一段 | 带上所在文件夹 |
| `late_start` 在 4 条对白片段里报了 3 条：台词本来就排在长镜头的后半 | 改为从这句台词所在镜头的计划起点算 |
| 默认字幕字体 Noto Sans CJK SC 这台机器上没有，渲染器悄悄换了字体；一台没有任何中文字体的机器会烧出一排方框而验收照样 OK | 默认取本机装有的中文字体；找不到请求的字体或一个中文字体都没有时报出来；自检新增「有没有能画中文的字体」 |
| 验收行只有 OK，上面的警告（片段里已有烧录字幕会叠字）容易被忽略 | OK 行注明有几条警告、验收不覆盖它们 |
| 没有参考图时真人门禁先去下载模型才发现没东西可比 | 先看有没有参考图 |
| 多句的 `action` 里，以人物短称开头的后续句子首字母小写 | 每句首字母大写 |
| 写不出性别词的角色（蒙面人）被写成 `closes their lips` | 新增可选的 `pronoun` 字段 |
| 风格句写成两句时，三段式开头读着别扭 | 并成一个逗号列表 |
| 机检对三段式不查长度，同样的内容在六段式里却报超长 | 长度提示两种版式都生效 |
| `cues.srt` 没有任何说明，容易被当成字幕 | 改名 `planned_cues.srt` 并写明只是计划时间 |
| 校验有错误时不打印总时长 | 总是打印 |

## 它核对后确认可信的

- 成片 885 帧、−14.1 LUFS、−1.3 dBTP，画面、声音、计划等长；每段首末帧与计划的源帧 PSNR 51–55 dB；各段音频滞后 0.0 ms；烧录字幕恰好落在字幕条目的帧上；单句 +7 dB 的增益实测 +6.9 dB。
- 质检的每一条判定：s01 尾部混入的下一镜画面、s02 多出的一个「大」、s03 的复读、s04 被识别成「好」的喷气声（无语音概率 0.58）、四条片段里已有的烧录字幕。
- 脚本看不到、它用眼睛看出来的：s02 里「快点快点」其实是蜂医的嘴在动（剧本写的是威龙）、眼睛发黄光、s03 的办公室和前后两段不是同一个、s04 里人物位置跳了一下。这些正是联络表加人眼那一步要管的。

## 没有解决的 / 没有验证的

- 字幕被挪到噪声上这件事，现在只能在「第二次对时结果和第一次不一样」时发现；第一次就对错了（识别器把开门声当成起点）仍然查不出，成片后要看一遍字幕。
- 音色检查在这支片子上 5 句里 4 句读不出（台词下面压着音效），帮不上「这句到底是谁说的」。
- 导出的工程没有在剪映 / Resolve 里打开过；`comfy_submit.py` 和身份门禁不在这一轮的范围里。
- 这一轮的修复没有再做独立复测。
