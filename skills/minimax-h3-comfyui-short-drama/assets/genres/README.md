# 类型包索引（genre packs）

本 skill 原本只有两套风格包（`../style-cinematic.md` 电影质感、`../style-manga.md` 漫剧），针对对白短剧调过。下面 13 个类型包补上其它常见题材。每个包写清：H3 在这一类里擅长什么、不擅长什么（附来源）；推荐模式与参数；风格句；镜头、表演、声音要点；参考素材怎么准备；一条已过 `scripts/lint_prompt.py` 的 10 s 完整示例；该类型的禁忌。

**怎么用**：先在下表选**一个**类型包，再叠一个画面风格（真人用 `style-cinematic`，2D 用 `style-manga`，3D 看 `08`）。类型包里的风格句会替换风格包的同名句子，其余规则仍以 `SKILL.md` 的铁律和 `references/` 为准。如果剧本跨两种类型（比如古装 + 打斗），就按段切换：文戏段用 `03`，武戏段用 `04`，不要在同一段里混用两套写法。

适配度：★5 = H3 直出就有优势；★3 = 可以做，但要按包里的绕法写；★2 = 只做短拍，关键镜头准备回退方案（参考视频驱动或换模型）。

## 跨类型通用结论

- **H3 最强的场景**：风格化动画（2D / 3D）、纯产品片、氛围光和声音细节、静态镜头里的细微面部表演。**最弱的场景**：快速动作与物理、slapstick、大特效与大幅运镜、画面里的精确文字。来源：官方 3D skill 的 `model-selection.md`、garycaogan 盲评、`references/model-and-modes.md` 列出的已知弱项。
- 弱项一律从分镜层面绕开：拆短拍、先写状态再写过程、特效绑在动作完成的那一刻、文字和 UI 后期叠加、关键镜头先出首帧或首尾帧。连续三次出现同样的问题就回到分镜层改写，或者换路线；不要靠反复换 seed 硬抽。
- 示例提示词里的人物、品牌、产品都是虚构的。真正使用时要把文本里的锚点换成参考图里**真实存在**的东西，参见 `SKILL.md`「和用户沟通时」一节。
