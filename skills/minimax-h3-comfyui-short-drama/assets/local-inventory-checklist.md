# Agent 提示词 · 盘点本地 H3 环境

> 用途：让 agent 只读地清点本机的 MiniMax H3 模型、ComfyUI 节点、工作流与硬件，产出一份结构化清单，作为后续接管流程的输入。复制下方代码块内容即可使用，方括号处可留空由 agent 自行探测。

```
任务：清点我本地的 MiniMax H3 视频生成环境，输出一份《本地环境清单》。这一步只读，不要修改、移动、删除任何文件，不要启动任何生成任务。

已知信息（不确定的留空，由你自行探测）：
- ComfyUI 目录：[/path/to/ComfyUI]
- ComfyUI 服务地址：[http://127.0.0.1:8188]
- 我的工作流 JSON 目录：[/path/to/workflows]
- 其他相关目录（整合包、启动器、输出目录）：[ ]

请按下面七个部分逐项探测并填写。每一项都要给出你是怎么得到的（命令或文件路径），拿不到的写「未知」并说明原因，不要猜。

## 1. 硬件与系统
- 操作系统与版本、Python 版本、PyTorch 版本、CUDA / ROCm 版本
- GPU 型号、显存总量、当前空闲显存（nvidia-smi 或 rocm-smi）
- CPU、内存、模型所在磁盘的剩余空间

## 2. ComfyUI 本体
- ComfyUI 版本或 git commit、启动方式（命令行 / 整合包 / 启动器名称）、启动参数
- 服务是否正在运行：访问 /system_stats 与 /object_info，记录返回的设备信息
- extra_model_paths.yaml 是否存在，指向哪些额外模型目录

## 3. H3 相关模型权重
在 ComfyUI/models 及 extra_model_paths 指向的目录里，列出所有与 MiniMax H3 相关的文件，每个记录：文件名、完整路径、大小、精度（BF16 / FP8 / GGUF 等，从文件名或 safetensors 头推断），并按角色归类：
- fl2va（文生 / 首尾帧主干）
- ref2va（参考生主干）
- text_encoder（Qwen3-VL 相关）
- visual_vae / audio_vae
- turbo_lora 或其他 LoRA
- 配套图像模型（Qwen Image Edit、Flux、SDXL 等，用于定妆图或一致性）
- 超分 / 插帧模型（如果有）
说明哪些角色缺失。

## 4. 自定义节点包
列出 custom_nodes 下的全部目录，对每个与 H3、视频、音频、一致性、LLM 相关的节点包记录：目录名、git remote 地址、当前 commit 或版本、是否能正常加载（看 ComfyUI 启动日志或 /object_info 里是否有它的节点）、它提供的主要节点名。重点确认是否有：
- MiniMax H3 官方 / 社区采样与加载节点
- Turbo LoRA 节点
- 多参考（Ref2VA）调度节点，支持的最大图 / 视频 / 音频数量
- 音频锁定或多说话人节点
- 提示词改写 / LLM 节点（本地 GGUF 或在线 API）
- 视频拼接、字幕、超分节点

## 5. 我的工作流
逐个打开工作流目录里的每个 JSON，为每个文件写一张卡片：
- 文件名、最后修改时间、格式（UI 格式还是 API 格式）
- 用途推断：T2V / I2V / FL2V / R2V / 纯音频 / 图像一致性 / 打戏润色 / 其他
- 输入槽位：提示词节点、参考图数量与节点、参考视频、参考音频、首帧 / 尾帧
- 关键参数默认值：宽高、时长或帧数、帧率、步数、采样器、调度器、CFG、seed、LoRA 及强度
- 输出节点与输出目录
- 依赖的节点包，是否全部已安装
- 你判断它能否通过 ComfyUI /prompt API 直接调用；若不能，说明缺什么

## 6. 既有产出与资产
- 输出目录里已有的视频数量、分辩率分布、时长分布、是否带音轨（用 ffprobe 抽样 5 个）
- 是否已有角色定妆图、场景图、音色参考等资产，存放在哪里

## 7. 工具链
- ffmpeg / ffprobe 版本
- 是否有可用的 LLM：本地（Ollama、LM Studio、llama.cpp，列出已下载模型）或在线 API 的环境变量名（只写变量名，不要输出值）
- 是否有 MiniMax 云端 API key 的环境变量名（同样只写变量名）

## 输出格式
1. 先给一张一页纸的《能力摘要》：我现在能做什么（最高分辩率、最长时长、是否出音频、是否支持参考音频、最多几张参考图），不能做什么，最明显的缺口是什么。
2. 再给上面七个部分的完整清单，用 Markdown 表格。
3. 最后列出你探测时遇到的问题和没有权限访问的路径。
4. 把完整清单另存为 local-inventory.md 放在我指定的目录：[/path/to/save]，没有指定就放在工作流目录旁边。

规则：只读；任何命令如果会写文件、下载、启动生成，先停下来告诉我；探测 ComfyUI 服务时只用 GET 请求。
```
