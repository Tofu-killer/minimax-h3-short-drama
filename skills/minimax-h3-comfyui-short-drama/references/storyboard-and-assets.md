# 分镜分段与资产（角色卡 / 场景 / 道具）

## 1. 生产单位是「段」不是「镜头」

一次 H3 生成 = 一段 4–15 s，内部 2–4 个子镜头，自带对白 + 音效 + 立体声。正反打在同一上下文里完成，不要再把每个镜头单独生成后拼接。

| 规则 | 数值 |
|------|------|
| 总时长估算 | 剧本字数 ÷ 500 字/分钟 |
| 段数 | 总时长 ÷ 12 s，±20% |
| 段长 | 硬范围 4–15 s（校验器）；本地开放权重的训练帧数约 124–362 帧，**实际从 5 s 起**（4 s 只有 107 帧，校验器会警告：生成 5 s 再在剪辑里裁）。对白段 8–12 s，动作 / 硬切镜头 5–8 s，爆点段 12–15 s；本地抽卡草稿阶段可先用 5–10 s；单段 ≤ 328 帧（4090 性能悬崖） |
| 子镜头 | 每段 2–4 个（校验器上限 4），每个 ≥ 1.2 s、常规 2.5–6 s；对白镜头 ≥ 3 s；对白段更严：10 s ≤ 2 镜、12–15 s ≤ 3 镜 |
| 台词预算 | **权威口径**：硬上限 总字数 ≤ (段长 − 2 s) × 4.5（校验器）；目标语速 3.3–4 字/s（实测自然），快档 ≤ 5 字/s 且连续 ≤ 3 s；其它文件里的 4 / 3.3 / 3.5–5 都是这条的不同侧面 |
| 节奏 | 禁止连续两段静态对话；每 3 段至少一次中/全景调度或动作急转 |
| 人物 | 单镜头有动作/台词的人物 ≤ 3；一镜一人开口；**单段说话人 ≤ 2**（≥ 3 人对话拆段）；同性别多说话人高危：声学画像反着写（音高 / 音质 / 语速），删掉 chuckle / 抽气类非对白人声 |
| 台词细预算 | 2 s 镜 ≤ 6 字、3 s ≤ 9、4 s ≤ 12，单镜 > 30 字必拆；标点停顿 ，0.2 s 。0.4 s …0.8 s；同场景连续动作 + 多句对白合成一段，禁一句一镜 |
| 段尾 | 末镜标 `end_hold`：末 1 s 前 0.5 s 运动收束，末 1 s 全体人物保持姿态站位、画面定格，拼接时剪掉这 1 s。**下一段要在同一场景接着演时**，末镜用中 / 中全景装下所有在场人物（禁大远景）、每人身后有一个可辨的背景锚点，这样结束状态看得见、能被 `observe_take.py` 核对；其余情况末镜按戏的需要收（特写、反应都可以） |

## 2. 分镜 JSON（见 `assets/episode.schema.json` 与 `assets/episode.example.json`）

每段必填：`segment_id`, `duration`, `scene_id`, `character_ids`, `prop_ids`, `shots[]`（景别/角度/运镜/动作/`dialogue[]`），`soundscape`, `music`, `end_state`（本段结束时每个人的位置、姿态、持物、光线、视线方向），`continuity`（从上一段继承的服装/道具/光线/方向）。

写法规范：
- 资产一律用占位符 `{asset_id}`（如 `{fengyi}`、`{office}`、`{prop_red_loot}`），生成提示词时才替换成 `<Subject N>` / `<Picture N>`。禁止手写编号。
- 动作句 ≥ 8 个英文词，并以句号结束后再写镜头句。
- `end_state` 与 `continuity` 不能为空；下一段的第一镜必须从上一段 `end_state` 开场。
- 不得发明目录外的角色/场景/道具 ID。
- 用 `scripts/validate_episode.py` 校验后再生成。

## 3. 资产定妆图（视觉事实源，整季复用）

| 资产 | 规格 |
|------|------|
| 角色 | 首选**两张单人单视图**：`face.png`（头肩特写，脸占满画面）放第一、`<id>_full.png`（正面全身）放第二，整季复用；白底、无文字无道具，各图年龄 / 脸型 / 发长一致；服装 / 年龄变体做子资产（`costume > age > 原图`）。把这几张拼成 16:9 设定板（左 1/3 头肩特写 + 右 2/3 正 / 侧 / 背）**给人审**。槽位不够（一段 ≥ 3 个角色）时可退回每角色一张设定板当参考。取舍的依据：`MiniMaxH3ReferenceToVideo` 的 `ref_image_size = match` 把每张参考等比缩到生成画布的像素面积（1344×768 ≈ 1 MP，不裁切、不放大；核心源码）——三视图板里每个人只分到其中一小块，单人图给同一张脸的像素多几倍；代价是每多一张参考，每一步都多带一份参考 token，更慢。两种挂法哪个更稳没有 4090 实测，样片段各跑一次再定；做法见 `image-stage.md` |
| 服装 | 画进参考图。进视频提示词的文字（`identity_phrase`）只写一眼可辨的不变量：发型发色、主服装与颜色、一个固定饰物；骨相、体型这些只对生图有用，放 `sheet_phrase` |
| 场景 | 两张：**无人 16:9 母版**（主机位轴、门窗家具主道具位置、光向）+ **3×3 九宫格多机位**（1 张 = 9 视角 = 1 个参考槽）；场景提示词固定开头「无人纯场景」，不含人名 / 衣物暗示 |
| 道具 | 白底单品图；**关键道具**（被拿起、展示、交接、给特写的）必须有图并绑进 `prop_ids`，否则模型一定会编；只带过一句的陈设（碗、抹布、门锁）不必建资产，写进动作描述即可，但不要给它特写 |
| 音色 | 每个主角 2–15 s 干净人声（无 BGM / 混响 / 削波）；**只给本段有台词的角色传音色**，音频 ≤ 3，音频不能是唯一参考；文件不存在就不引用（LoadAudio 缺文件会让整图被拒） |
| 数量 | 图 ≤ 9 / 视频 ≤ 3 / 音频 ≤ 3 / 总 ≤ 12；实测 ≤ 6 个最稳。取材优先级（决定「带哪些」）：首尾帧锚图 → 主角板 → 场景母版 + 九宫格 → 配角 → 道具拼板 → 动作参考视频 → 音色；接线顺序（决定编号）由 `build_prompts.py` 固定为 首帧锚（若有）→ 角色 → 场景 → 道具 → 音频。每个参考写 Role / Retention / Allowed change / Forbidden drift 四栏；定义了不引用的参考删掉 |
| 含文字 / UI 的图 | 只能作 Ref2VA 弱参考（构图 / 风格），不能当 I2VA 首帧；首帧必须是可直接用的字面首帧，不是拼贴设定板 |

用 H3 自己出角色三视图/场景图/剧照的方法见 `quality-pipeline.md`（Contact-Sheet / OrbitSheets / Still 节点）。

## 4. 一致性三层

1. **片段内**：每个参考文件一个职责（脸 / 服装 / 环境 / 道具 / 音色），职责不重叠；`Never transfer facial traits from <Picture 3>`。
2. **片段间**：命名终态（`end_state`）→ 下一段开场。**计划末态用来写分镜，实拍末态用来写下一段**：take 被采纳后跑 `scripts/observe_take.py`（出首帧 / 中段 / 末帧的观测表，把从末帧上读到的每人位置、朝向、姿态、持物、道具位置写回分镜的 `observed_end_state`，与计划不同处记进 `accepted_deviations`）；下一段的 `continuity` 写 `"@observed"` 就会自动从它开场，没观测过则 `build_prompts.py` 拒绝出这一段的提示词（草稿阶段加 `--allow-planned` 先用计划值）。帧上读不到的东西（动作有没有做完、运镜到哪一相位、声音）不写进去。硬切到别的场景的段不需要这一步。另外：用 `scripts/extract_tail_frame.py`（ffprobe duration − 0.2 s）截末帧作下一段首帧 / 参考，**同时**带长期母版（角色参考 / 场景母版）与短期状态（末帧），只用末帧会传播漂移；下一段首镜以同档景别起手；上一段失败则回溯更早成功段的末帧，再不行降级 T2V，链不断。latent 续接见 `continuity-long-video.md`。场景描述写一遍后原样粘贴；一次性事件写明次数（`the door opens exactly once`）。
3. **集间**：同一组定妆图 + 同一组识别短语/声音短语逐字复用，存进「系列圣经」。

## 5. 镜头设计规避风险

- 要看清脸用中近景/特写；远景用背影、3/4 背面或空镜（`never show a distant frontal face`）。
- 关键脸部镜头与关键道具镜头（拿起 / 展示 / 交接）走 I2VA 首帧而不是纯 Ref2VA。
- 一次只改一个变量；中途不许变身、换装、换发型。
- 每镜画面按七层写：精确人数正向锁（`exactly two characters, each appearing once`）→ 身份 / 发型 / 服装与资产表一字不差 + 「参考图只继承身份发型服装，排除姿势构图背景光线」→ 空间与唯一道具 → 动作因果链 → 摄影机三件套（起点构图 + 一个主运动 + 终点构图）→ 光色材质 → must_hold / changes_here。
- 拟音禁「啪 / 砰 / 轰 / 炸 / 爆」类词（会触发爆炸视觉）。
- 口型镜头：近景用裁出的半身图而非全身三视图，第一句写景别，一条只给一句台词，3/4 侧脸，不要麦克风挡嘴。
- 物品等级框、UI、字幕后期叠。

## 5b. 写每一段时再过一遍（别的流水线里反复出现的做法，`docs/14-ai-video-workflows/02`）

- **只写这一段发生的事**：动笔前把事件分成「已经发生的 / 只在这一段发生的 / 留给后面的」，提示词只写中间一栏。上一段做完的动作这一段不重演，后面才发生的事这一段不出现（模型会抢戏）。
- **每个镜头至少承担一件事**：改变情绪、推进动作、增加压力三选一；三样都不沾的镜头删掉。写的时候各给一个环境压力、一个身体上的小动作、一个声音或视觉母题。
- **反应镜的写法**：触发 → 一个准确的情绪词 → 两处在当前景别里看得见的身体变化 → 1.5 s 内落定并保持。重大信息的反应分「僵住 → 确认 → 释放」三层，一镜只演一层。
- **标了时码就把时间填满**：各镜时长相加恰好等于段长——超了句尾被截，留白会被慢放拖长。
- **描述目标画面，不下编辑指令**：生成提示词里不用「增加 / 删除 / 替换 / 改成 / 延长 / 续写」这类词（那是编辑模型的语法）；参考图已经给出的外貌和陈设不再用文字重复，文字专心写构图、此刻的位置状态和姿态。
- **改了画面动作就同步改 `soundscape`**：声景也是动作指令，画面里已经没有的东西还留在声景里，模型会把它画回来。
- **开场站位写成数据**：多人场景的第一段在分镜顶层 `stagings` 里登记谁在哪件东西旁、画面哪一侧、站还是坐、面朝哪（字段见 `assets/episode.schema.json`）；`build_prompts.py` 据此在该段开头生成一句固定的走位句（`<Subject 1> sits at the left end of the sofa on the left side of the frame, facing frame right; … Exactly two people are in the scene; the other seats stay empty.`），校验器会拦：没在这一段出场的人被摆了位置、两人挤在同一处、`at` 用了场景描述里没有的东西。这样同一个站位每次都是同一种说法，不靠每段自由发挥。
- **位置变化必须对应剧本里的移动事件**：谁从哪走到哪要有一句动作交代；相邻两段先判断是「连续」（用 `"@observed"`）、「只继承持续状态」（服装、光线、持物）还是「重新锚定」（换场景，从角色参考与场景母版重来）。
- 首帧模式的对白段常有一段起音延迟：用 `qc_dialogue.py` 报告里的首字时间看自己机器上的分布，再决定给台词留多少预卷、剪辑时裁多少片头（别的团队在云端 H3 上量到 1.3–2.4 s，本地权重未验证）。
- 要严格锁首帧构图的段，先别同时挂音色参考做对比：有团队报告 H3 一挂音频或多图参考就不再硬锁首帧（云端 API 经验，本地权重未验证）；这类段的音色一致交给后期。

## 6. 风格包

- 电影质感 / 漫剧两套风格句与反例见 `../assets/style-cinematic.md`、`../assets/style-manga.md`（来自仓库 `templates/`）。
- 漫剧补充：先按题材选风格总表一行（美术风格 / 主色 / 光影 / 渲染后缀），全片统一禁混用；3D 国漫加「3D国漫渲染、卡通材质、描边、赛璐璐」，三渲二加「3D 模型精度 + 2D 手绘笔触、强逆光轮廓光」；角色参考图全 3D 不出真人版；不用真人负面词，改锁比例 / 轮廓 / 线宽 / 色板 / 变形边界；五官按词表逐人写具体；夸张表情用「表情符号式」描述（`eyes widen into round white circles, sweat drop`）。
- 合规替换（不删剧情只换词）：血 → 金色血液 / 衣领红痕 / 光影符文；暴力 → 格挡弹开光点消散；裸露 → 高领一字肩立体剪裁。
- Ref2VA 视频编辑 / 换人：短提示会原样照抄参考视频；必须六段式且 `summary` 以 `[video editing + reference generation] The target video is an edited version of <Video 1>.` 开头，写「原片是 X，换成 Y」对比句，一次只加一句修改。
