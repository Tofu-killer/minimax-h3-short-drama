# QC 与拼接

## 1. 两层 QC，技术通过 ≠ 整体通过

**技术 QC（脚本自动，`scripts/qc_probe.py`）**：ffprobe + 全解码；分辨率 / 时长（与请求帧数一致）/ 24 fps / 音轨存在；`blackdetect=d=0.25:pix_th=0.05`（意外黑帧 > 0.25 s 为硬门）；`freezedetect=n=-60dB:d=1`（冻结 > 1 s 为硬门，声明的段尾定格除外）；响度 `loudnorm I=-14:TP=-1.5`，峰值 > −1 dBTP 为硬门。

**硬门 / 软警**：硬门 = 文件不可解码、缺镜 / 缺节拍、尺寸帧率时长违约、身份 / 服装 / 道具 / 轴线显著错、音频削波、意外黑帧、冻结。软警 = 轻微拖影、背景小漂移、音量不均。技术 PASS + 人眼未审 ≠ 通过。

**视觉 QC（人工看联络表，`scripts/contact_sheet.sh`）**：
- 身份：脸是否与参考一致，是否「换人」；
- 服装/道具：颜色、形状、件数；道具是否被替换成虚构物；
- 环境：布局、光线方向、色温是否与上一段连续；
- 动作：是否瞬移、是否多余肢体、手部是否崩；
- 镜头：是否按分镜切镜、运镜是否漂移；
- 字幕安全区：下方 15% 不放关键信息。

**自动台词质检**（Whisper 逐词模式）：整句相似度 < 0.72 FAIL；开头 / 结尾 3 词丢失 FAIL；转写词数 > 台词 × 1.15 + 2 判插词；FAIL 自动换新 seed 重出 ≤ 3 次，同类问题连续 2 次回去改分镜。

**动作量 QC**（相邻帧灰度差，240 px 宽）：动作镜 ≥ 2.5、特写动作 ≥ 1.8；任何镜 < 1.0 判冻结、< 1.2 才重跑；全片跑完后再按「低于本片中位数 45%」相对判定；亮度 < 8 黑屏、std < 3 纯色。

**音频 QC**：抽听对白与 `<d>` 文本一致、语言正确、无错人开口、无重复台词、无音画不同步；句尾是否被截断。

硬门禁不过只允许重试一次；连续两次失败改提示词或分镜，不要无限抽卡。

**失败码 → 责任层**（修复从上游开始：资产 → 剧本/导演 → 分镜/提示词 → 重生成 → 后期）：

| 码 | 现象 | 责任层 / 最小修复 |
|----|------|------|
| F-COUNT | 人数不对、多出一人 | 提示词：精确人数正向锁；群像先写人数 |
| F-ID-DRIFT | 换脸 / 换装 / 发型变 | 资产：角色板是否在参考包；提示词：只写不变量 |
| F-STATE-DRIFT | 位置 / 持物 / 光线与上段不接 | 分镜：`end_state` / `continuity`；同时投喂母版 + 末帧 |
| F-REF-SCOPE | 照抄参考图背景 / 姿势 | 提示词：「参考图只继承身份发型服装，排除姿势构图背景光线」 |
| F-PROP | 道具虚构 / 替换 | 资产：道具图进参考包 + `the exact item shown in <Picture N>` |
| F-LIPSYNC | 错人张嘴 / 口型不对 | 分镜：一镜一人开口；听者闭嘴；音色只给说话者 |
| F-DIALOGUE-TEXT | 台词复读 / 漏句 / 含糊 | 提示词：台词只写一次、预算；步数 ≥ 8 或 12 |
| F-BURN-TEXT | 画面烧出字幕 | 提示词：正文太短（< 350 词）或要求了字幕 |
| F-SEAM | 接缝闪帧 / 曝光跳 | 后期：统一转码；续接：见 continuity |

每条 QC 问题记：集‑时间码‑镜头 / 任务 ID‑类型‑证据‑根因‑修复层级‑复验状态。冷观众四问（想要什么 / 什么阻止 / 什么变了 / 为何结局）任一答错即 P0。

## 2. 抽卡策略

- 草稿档每段 2 个 seed（关键镜 3），用 **5 帧联络表**挑而不是看视频：先看角色一致性，再看能量 / 表演。
- 四维评分（`assets/judge-take-prompt.md` 给本地 Qwen3-VL）：台词听回比例（ASR 对照 `<d>`）× 与角色板相似度 × 无冻结 × 相对清晰度；生态里没有开源的「本地抽卡→VLM 评分择优」，这是本 skill 自补的环节。
- 中选后**同 seed 精修 / 二采**，不换表演。
- 一次重抽只改一个变量（seed / 一句提示词 / 一个参考）；同一错误连续两批无改善回上层（资产 / 镜头拆解）。
- 记录每段「seed / 步数 / LoRA 版本 / 分辨率 / 耗时 / 显存 / 主观评分」到 `logs/takes.csv`，一周后用数据定默认值。
- 同一提示词连抽 3 次都出现同一问题 = 提示词问题，不是运气。

## 3. 拼接

-1. **逐 take 响度归一**：H3 takes 在 −26…−10 LUFS 间漂，Turbo take 比 20 步响 1.7–4.3 LU；剪前每 take `loudnorm` 到 −16 LUFS，成片 −14 LUFS / −1.5 dBTP。字幕时间可用 `silencedetect` 按台词句数自动分配再人工校。
0. 先剪掉每段末 1 s 声明的定格；检测并裁掉 H3 开头 0.02–0.15 s 的「起始音节」（前 0.6 s 内 < 0.3 s 高能段后接 0.2 s 低能）。
1. 全部段统一转码为相同编码参数（contain-pad 1920×1080、24 fps、AAC 48 kHz 立体声；H3 原生音频是 32 kHz，段间响度可差 9 LU，必须 loudnorm 统一），再 `ffmpeg -f concat -safe 0 -i list.txt -c copy`，避免重编码造成音画不同步。
2. 字幕来自分镜 JSON 的 `dialogue[]`（已有时间码），生成 SRT 后烧录；不要让模型画字幕。
3. 配乐：各段 `non_diegetic_music: N/A`，剪辑阶段统一铺全集配乐；对白处 duck −8 到 −12 dB；硬切点对齐 1/4 或 1/8 拍。
4. 开头 3 s 剪到最紧；片尾加下一集卡片。
5. 交付 16:9：1920×1080（768P 草稿 1344×768 → 精修/超分到 1080p）；24 fps 或转 30 fps；AAC 立体声。

## 4. 产物目录（可复现）

```
project/
├── project.yaml           # 风格、画幅、模型组合、LoRA 版本
├── bible/                 # 角色/场景/道具卡 + 识别短语 + 音色样本
├── episodes/ep01.json     # 分镜
├── prompts/               # 每段最终提示词（含替换后的标签）
├── takes/ep01/seg03/      # 每个候选 mp4 + 参数 json
├── selects/               # 中选
├── final/                 # 精修/超分后
├── qc/                    # 联络表、ffprobe 报告
└── logs/takes.csv
```
任何一段都能从 `prompts/ + bible/ + project.yaml` 重新生成。
