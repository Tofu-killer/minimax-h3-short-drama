# QC 与拼接

## 1. 两层 QC，技术通过 ≠ 整体通过

**技术 QC（脚本自动，`scripts/qc_probe.py`）**：ffprobe 校验分辨率 / 时长（与请求帧数一致）/ 24 fps / 音轨存在 / 峰值不削波 / 无黑场与冻结帧（`freezedetect`）。

**视觉 QC（人工看联络表，`scripts/contact_sheet.sh`）**：
- 身份：脸是否与参考一致，是否「换人」；
- 服装/道具：颜色、形状、件数；道具是否被替换成虚构物；
- 环境：布局、光线方向、色温是否与上一段连续；
- 动作：是否瞬移、是否多余肢体、手部是否崩；
- 镜头：是否按分镜切镜、运镜是否漂移；
- 字幕安全区：下方 15% 不放关键信息。

**音频 QC**：抽听对白与 `<d>` 文本一致、语言正确、无错人开口、无重复台词、无音画不同步；句尾是否被截断。

硬门禁不过只允许重试一次；连续两次失败改提示词或分镜，不要无限抽卡。

## 2. 抽卡策略

- 草稿档每段出 N=2–4 个候选（不同 seed），挑最佳；只对中选候选做精修。
- 记录每段「seed / 步数 / LoRA 版本 / 分辨率 / 耗时 / 显存 / 主观评分」到 `logs/takes.csv`，一周后用数据定默认值。
- 同一提示词连抽 3 次都出现同一问题 = 提示词问题，不是运气。

## 3. 拼接

1. 全部段统一转码为相同编码参数（H.264 high、24 fps、AAC 48 kHz 立体声、相同分辨率），再 `ffmpeg -f concat -safe 0 -i list.txt -c copy`，避免重编码造成音画不同步。
2. 字幕来自分镜 JSON 的 `dialogue[]`（已有时间码），生成 SRT 后烧录；不要让模型画字幕。
3. 配乐：各段 `non_diegetic_music: N/A`，剪辑阶段统一铺全集配乐；对白处 duck −8 到 −12 dB；硬切点对齐 1/4 或 1/8 拍。
4. 开头 3 s 剪到最紧；片尾加下一集卡片。
5. 交付 16:9：1920×1080（768P 草稿 1344×768 → 精修/超分到 1080p）；24 fps 或转 30 fps；AAC 立体声。

## 4. 产物目录（可复现）

```
project/
├── project.yaml           # 风格、画幅、模型组合、LoRA 版本
├── bible/                 # 角色/场景/道具卡 + 识别短语 + 音色样本
├── episodes/ep01.json     # 分镜
├── prompts/               # 每段最终提示词（含替换后的标签）
├── takes/ep01/seg03/      # 每个候选 mp4 + 参数 json
├── selects/               # 中选
├── final/                 # 精修/超分后
├── qc/                    # 联络表、ffprobe 报告
└── logs/takes.csv
```
任何一段都能从 `prompts/ + bible/ + project.yaml` 重新生成。
